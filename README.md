# My Homepage

Personal portfolio website for Muhammad Ammar Nuqman Bin Anuar.

The site uses a deliberately simple early-2000s homepage style with:

- A table-based layout
- Classic bright link colors and bordered content boxes
- Resume-based education, experience, achievements, skills, and languages
- Email, GitHub, LinkedIn, and guestbook links
- A lightweight static HTML implementation

## Local preview

Open `index.html` directly in a browser, or serve the repository with any static file server.

## GitHub Pages

The live site is available at:

<https://ammxr13.github.io/>

GitHub Pages is currently configured to publish from the `assignment` branch. If the portfolio is maintained on `main`, update the repository's Pages source branch in **Settings → Pages → Build and deployment**.
